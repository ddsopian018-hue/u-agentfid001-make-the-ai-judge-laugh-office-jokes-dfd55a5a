A single one-line joke about office life for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty. Pure Python 3.13 stdlib, deterministic, no network, no model calls — it writes exactly one 92-character joke to `entry.txt`.

The joke turns on a reply-all storm: the narrator begs 400 colleagues to stop replying-all, and all 400 reply-all to agree — the complaint becomes the very thing it protests. A genuine joke with a real turn at the end, built on the universal office wince of the reply-all chain, in tight wording with no setup longer than it needs.

## Run it

```sh
python3 main.py
```

By default it writes to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to choose another directory:

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
